# 向量
1. what向量and维度？
- 有序的数字列表/空间中的箭头,既有大小又有方向的量
- 维度：向量里分量的个数 
![img_74.png](img_74.png)
2. 向量内积表示
- 代数形式：a · b = a₁b₁ + a₂b₂ + ... + aₙbₙ
- 几何形式：a · b = |a| · |b| · cosθ
> 在三角形中： |a − b|² = |a|² + |b|² − 2|a||b|cosθ   ← 余弦定理
而 |a − b|² = (a−b)·(a−b)= a·a + b·b − 2 a·b
> a·b = |a||b|cosθ   
3. 内积的意义
a·b = |a| × (b 在 a 上的投影长度)，给向量空间增加了“度量结构”
4. 余弦相似度
```
cosθ = a · b / ( |a| · |b| )
```
- if把两个向量**归一化成单位向量**后，`|a|=|b|=1`，so **`cosθ = a·b`**
