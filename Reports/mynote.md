## main
1.tqdm 是一个 Python 库，作用是给循环加上进度条，让你能直观看到代码运行到哪一步了。在训练时用 tqdm 包装 dataloader，运行时就会显示 “当前 batch / 总 batch 数”“训练时间”“损失值” 这些信息，方便监控训练过程
- `eave=True`:当这个进度条跑完（比如一轮训练结束）后，进度条不会消失，会保留在终端里
## utils
1. 为什么算psnr时datarange=1?
> 原始的图数据在处理（dataset）totensor一步已经将tensor转为numpy数组的同时归一化，归一化之后像素的最大值就从255->1
> 而输出后的数据经过clip修建极端异常值范围也被限制为0~1
```python
# 用cv2.imread / PIL读出来原始图片，类型uint8，像素 0~255
img = cv2.imread("xxx.png") # shape H,W,C，数值0~255，整数
psnr(img1, img2, data_range=255)
```
2. 线性归一化
假设原始数据是 [x_min,x_max]，归一化到 [a,b] 范围，公式是`y = (x - x_min)/(x_max - x_min) * (b - a) + a`
通过`(x - mean)/std = 线性变换公式`可反推计算出mean和std
3. **为什么连优化器状态一起存 / 读
** 如果只存模型参数（`model.state_dict()`），中途中断后再训练，Adam 的动量是空的，相当于 "冷启动"，前几个 batch 更新会不稳。把优化器状态一起存，才能**无缝续训**
## unet
1. InstanceNorm 和 BatchNorm 区别
- InstanceNorm：对**单张图片单独归一化**，图像复原、风格迁移常用；
- BatchNorm：在一个 batch 内部做归一化，分类网络更常用。
> InstanceNorm 是对单张图片的每个通道单独做归一化，能保留图片本身的对比度和风格信息，而雨滴的去除需要精准还原单张图片的细节。
> BatchNorm 是对一个 batch 里的所有图片一起归一化，容易受 batch 内其他图片影响，可能导致图片整体亮度、色彩失真，反而破坏雨滴和干净图的对应关系
2. 为什么要设bias=false
- 后面接了 InstanceNorm 归一化层，归一化会把特征的均值和方差调整到固定范围，这时候卷积层的偏置参数会被归一化操作 “抵消” 掉，留着偏置相当于多了无用的参数，还会增加计算量
- 用 BatchNorm 时，也推荐把卷积层的 bias 设为 False。因为 BatchNorm 的计算式里包含了 β（偏置参数），它会自动学习特征的偏移量，这时候卷积层的偏置就显得多余了，留着反而可能影响归一化效果
3. nn.Sequential
- 把多个神经网络层按顺序 “串” 起来，前一层的输出直接作为后一层的输入，不用手动写每层的连接逻辑
4. nn.ModuleList
- PyTorch 里自带的类，专门用来存放多个神经网络层，并且能自动管理这些层的参数，让它们能被训练到
5. 转置卷积
- 转置卷积的滑动步长是 1，中间扩展后的图（通过插入空白来先变大）经过卷积后尺寸不变，最终的放大效果完全来自 “扩展步骤”—— 通过输入尺寸、kernel_size 和 stride 计算出扩展后的中间图大小，这一步直接决定了输出尺寸
